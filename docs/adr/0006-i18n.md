# ADR-0006 — Languages, terminology and localisation

Status: accepted, built in Phase 4 · Date: 2026-11-10

## Decision

Stable message keys with ICU MessageFormat (formatted with `intl-messageformat`; `next-intl` was not
needed, since the server picks the language per request), resolved through three layers:

1. the built-in catalog for the locale (English and Spanish complete at launch);
2. the tenant's terminology pack;
3. the tenant's own overrides from the translation editor.

The reference's English-sentence-as-key dictionary and its `_es` columns are not carried over.

## Terminology

Role and domain words are terms, not strings: every message receives `{termChair}`,
`{termChairs}`, `{termDelegate}`, `{termHighCommand}`, `{termCommittees}` and the rest as
arguments. Singular and plural are separate terms. Packs (UN style, Secretariat, School,
Reglamento) define them in English and Spanish; a school can override any term in any language.

Not done: grammatical gender and articles inside sentences ("the Chairs" vs "la Mesa"). Messages
avoid putting an article before a term; if a language needs it, its translation can use an ICU
`select` on a term-gender argument, to be added when a customer needs it.

## Two locales at once

- Interface locale: the tenant default, overridable per person (saved on the profile, or in a
  cookie for visitors). The browser's language is deliberately not used.
- Committee locale: set per committee; drives the chair console and projection screen.

Which parts follow which (the reference keeps the top bar out of committee language) is a setting.

## Any language

A tenant enables any BCP-47 locale. The translation editor lists every key with its source text,
shows where it appears, validates ICU placeholders, and can import and export CSV or JSON. The
missing-string report covers only the locales the tenant has enabled; a missing string falls back
along the tenant's fallback chain and is reported, never blank.

Tenant-authored content (committee names, rubric wording, announcement text, email templates) is
stored as a map of locale to text.

## Right-to-left

`dir` comes from the locale. Components use logical CSS properties only (enforced by lint, ADR-0005),
directional icons mirror, and the projection ticker reverses direction. Arabic is the test locale in
Playwright screenshots.

## Formats, countries and flags

Dates, times, numbers and lists use `Intl` with the tenant's time zone and format preferences.
Country names in any language come from `Intl.DisplayNames`; the alias and formal-name tables that
make "República Federal de Alemania" resolve to a flag are ported as data per locale and are
editable. Flag sets (countries, US states, tenant uploads) are a registry, not file paths in code.
Since Phase 5 each committee type names its flag source and each committee its own language.

## Guard rails

CI fails on a literal user-facing string in a component, on a key missing from English or Spanish,
and on an ICU placeholder mismatch between locales.
